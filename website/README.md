# Maven website

A single static page (`index.html`): no build step, no dependencies beyond Google Fonts.

Deploy it anywhere that serves static files:

- **Netlify / Vercel / Cloudflare Pages:** drag this folder into a new project, or point the project at it.
- **GitHub Pages:** put `index.html` in a `docs/` folder of the Maven repo and enable Pages for `docs/`.

Before launch, replace the placeholder `maven-cmo/maven` (install commands and footer links) with your real GitHub path. The weekly brief and agency table in the page are labelled samples with illustrative numbers. Keep that label, or swap in real numbers from a customer who agreed to it.
